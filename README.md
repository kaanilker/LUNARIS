# LUNARIS

Lunar Illumination & Communication Analysis System. Quasar Team, NASA Space Apps Challenge 2026.

This repository holds the built static site in `build/`. Upload the contents of `build/` to the web root.
The AI comment endpoint `build/api/yorum.php` reads `GROQ_API_KEY` from a `.env` file kept outside the web root;
the key is never stored in this repository.
